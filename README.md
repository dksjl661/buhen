# 步痕

一小本可以单步演示的算法课。没有账号，也没有后端。每按一次，只发生一件事，旁边写着这一步在守什么。

- 二分查找：有序数组里，边界怎么一次丢掉一半
- 冒泡、选择、插入：同一排数上的三种手法，以及各自的不变量
- 广度优先和深度优先：同一张图，队列和栈走出不同的顺序

方向键是上一步和下一步，空格是播放。

## 本地看

用模块脚本，需要从一个本地服务器打开，直接双击文件浏览器会拦掉。

```bash
python3 -m http.server 8080
```

然后打开 http://localhost:8080 。
