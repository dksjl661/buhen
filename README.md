# 步痕

按章节排开的算法课。每题只走一个具体例子，每按一次只发生一件事，旁边写着这一步在守什么。

章节和代码随想录的地图一样：数组、链表、哈希表、字符串、双指针、栈与队列、二叉树、回溯、贪心、动态规划、单调栈、图论。讲解和例子是这里自己写的。

方向键是上一步和下一步，空格是播放。地址栏的 `#题号` 可以直接打开某一题。

## 本地看

```bash
python3 -m http.server 8080
```

然后打开 http://localhost:8080 。
